William & Mary MBWA Inspections
================================

A native iOS app for recording "Management By Walking Around" (MBWA) inspection
findings on the William & Mary campus. Fully offline (SwiftUI + SwiftData),
with email-based export of PDF reports and CSV summaries.

## Requirements

- macOS with Xcode 15 or newer (iOS 17 SDK)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) — `brew install xcodegen`
- A physical device for camera capture (Simulator supports the photo library)

## Build

```bash
./bootstrap.sh           # generates WMInspections.xcodeproj
open WMInspections.xcodeproj
```

Then choose an iOS 17+ simulator (or a connected device) and Run.

## Project layout

```
WMInspections/
  WMInspectionsApp.swift            App entry, ModelContainer, first-launch seed
  Info.plist                        Generated by XcodeGen from project.yml
  Resources/
    CampusLocations.json            Bundled campus hierarchy (9 groups)
  Models/                           SwiftData @Model types + enums
  Views/
    Inspections/                    List, row, detail, editor screens
    Pickers/                        Location / Sub-location / Category pickers
    Photos/                         Camera, PHPicker, thumbnail grid, full-screen viewer
    Settings/                       Settings, location editor, about
    Export/                         Export options, mail composer, share sheet fallback
  Services/                         Photo storage, JSON seed, CSV/PDF builders, app settings
  Extensions/                       Small helpers (date formatting, image resize)
```

## Features

- **Active / Inactive tabs** with search, swipe Close / Reopen / Delete, and an
  Add (+) floating button.
- **New / Edit inspection** with hierarchical location picker, contextual
  sub-location pick list (or custom entry), category, free-text notes, and
  multiple photos via the camera or photo library.
- **Photos** are saved full-resolution under `Documents/Photos/` with 200×200
  thumbnails under `Documents/Thumbnails/`.
- **Settings** for the default export email (pre-filled with
  `schughes@wm.edu`), an "Attach original photos separately" toggle, and a
  CRUD editor for the campus location list.
- **Export** selected records as a CSV summary or as one PDF per record (with
  photos rendered inline). When mail isn't configured the Share Sheet is used
  as a fallback.

## Manual verification

1. First launch — Active list empty; Settings → Locations shows all 9 groups.
2. Create an inspection with a library photo and another with the camera (on a
   device).
3. Swipe a row to Close it; switch tabs and Reopen it.
4. Use Edit mode to multi-select records, then Export List (CSV) and Export
   with Photos (PDF). Confirm the mail composer opens with attachments.
5. Toggle "Attach original photos separately" and verify the JPEGs ride along.
6. Add a custom location in Settings → Locations and use it in a new record;
   relaunch the app and confirm both persist.
