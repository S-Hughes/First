# CLAUDE.md

Guidance for Claude Code (and any AI assistant) working in this repository.

## About this repo

This is **First** — a personal **starter/template repository**. It is intentionally
general-purpose and **language-agnostic**: it gets cloned as the seed for new
projects, which may be CLIs, scripts, web apps/APIs, or learning exercises. There is
no committed application code yet, so most decisions are made per-project at the time
the template is used.

When a new project is started from this template, **update this file** to record the
actual language, stack, and commands for that project.

## How to work with me

- **Explain as you go.** I'm learning. Walk me through what you're doing and why,
  especially anything non-obvious. Define new terms the first time they appear.
- **Ask before big or hard-to-reverse changes.** Confirm before large refactors,
  deleting/overwriting files, changing project structure, adding heavy dependencies,
  or anything that's awkward to undo. Small, obvious steps don't need a check-in.
- **Write tests.** Add or update tests alongside code changes. When a language/stack
  is chosen for a project, pick a standard, well-supported testing framework for it
  and note it here.

## Git workflow

- **Commit freely** as work progresses — small, logical commits are good.
- **Push only when I ask.** Do not push to a remote unless explicitly told to.
- **Don't open pull requests** unless I explicitly request one.
- **Commit messages:** use clear, descriptive messages. Conventional Commits style
  (`feat:`, `fix:`, `docs:`, `chore:`, `test:`) is a good default and helps me learn
  good habits — use it unless a project calls for something else.
